# Лабораторная работа №2 - Дерево объектов QObject в Qt

Лабораторная работа №2 по дисциплине ОКП.

Демонстрация механизма владения объектами в Qt: родитель автоматически
удаляет своих детей, а `setParent()` меняет владельца во время выполнения.

---

## Цель работы

Изучить понятие дерева объектов `QObject`, понять принцип владения
родителя над дочерними объектами, научиться создавать виджеты с явным
родителем и продемонстрировать автоматическое удаление детей при
удалении родителя.

---

## Что демонстрирует программа

- Создание **9 виджетов** с явными родителями.
- Логирование `[CREATE]` / `[DESTROY]` в консоль через `qDebug()`
  в конструкторах и деструкторах производных классов.
- **Автоматическое удаление детей** при удалении родителя.
- **Смену владельца** через `setParent()` с обязательным обновлением layout.
- **Отвязку** через `setParent(nullptr)` и ручное удаление через `deleteLater()`.
- Безопасное хранение указателей через `QPointer`.

---

## Требования

- **Qt** 5.15+ или 6.x с модулем `widgets`
- Компилятор с поддержкой **C++17** (MinGW, MSVC, GCC, Clang)
- **qmake** (идёт в комплекте с Qt)
- **Qt Creator** (рекомендуется) или командная строка

---

## Сборка и запуск

### Вариант 1 — Qt Creator (рекомендуется)

1. Откройте Qt Creator.
2. **File → Open File or Project…** → выберите `okp_lab2.pro`.
3. Выберите kit (Desktop Qt …).
4. Нажмите **Run** (Ctrl+R или зелёный треугольник).
